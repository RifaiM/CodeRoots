📋 Project Requirements

Your portfolio website must fulfill the following criteria:

1. HTML Requirements 🏗️

  • Header with navigation links
  • Hero section with intro & photo
  • About me section
  • Projects grid with at least 2 projects
  • Contact form with input fields

2. CSS Requirements 🎨

  • Custom color palette using CSS variables
  • Flexbox or Grid layout
  • Responsive layout (mobile friendly)
  • Hover transitions on buttons & links

3. JavaScript Requirements ⚡

  • At least one event listener (click/submit)
  • Dynamic DOM manipulation
  • Form submission alert or validation
