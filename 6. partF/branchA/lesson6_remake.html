GitHub Actions CI/CD Automation | Track 7A

🤖 Lesson 6: GitHub Actions CI/CD Pipeline ☁️ Track 7A • Lesson 6/6 (FINAL)

1. Create Workflow File (`.github/workflows/deploy.yml`)

GitHub Actions automatically triggers automated testing and deployment whenever new code is pushed to your `main` branch.

2. Configure Automated Test & Build Steps

Define your workflow yaml configuration:

name: CI/CD Pipeline on: push: branches: [ main ] jobs: test-and-deploy: runs-on: ubuntu-latest steps: - uses: actions/checkout@v4 - name: Set up Python / Node uses: actions/setup-node@v4 with: node-version: '20' - run: npm install - run: npm test - name: Deploy to Vercel / Cloudflare run: echo "Automated Deploy Success!"

3. Repository Secrets Management

Store encrypted deployment API tokens under GitHub Settings ➔ Secrets and variables ➔ Actions (e.g., `VERCEL_TOKEN` or `CLOUDFLARE_API_TOKEN`).
