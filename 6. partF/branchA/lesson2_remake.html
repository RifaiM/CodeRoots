▲ Lesson 2: Deploying to Vercel & Netlify ☁️ Track 7A • Lesson 2/6

1. Import GitHub Repository to Vercel

Log into Vercel.com using GitHub. Click New Project and import your target repository.

2. Build Command & Output Directory

Configure project build settings based on your frontend framework:

Framework Preset: Vite / React Build Command: npm run build Output Directory: dist

3. Environment Variables Configuration

Add production API keys under Project Settings ➔ Environment Variables:

VITE_API_URL=https://api.myproject.com VITE_ENABLE_ANALYTICS=true

4. Deploying via Vercel CLI (Optional Terminal Method)

You can also deploy directly from your local terminal using the Vercel CLI:

npm i -g vercel vercel --prod
