📚 Lesson 1: Git & GitHub Workflow ☁️ Track 7A • Lesson 1/6

1. Initialize Local Git Repository

Every production cloud deployment starts with Git tracking. Initialize your project folder:

git init

2. Create a .gitignore File

Never push sensitive environment variables (`.env`) or heavy dependencies (`node_modules/`, `venv/`) to public repositories:

echo "node_modules/\n.env\n__pycache__/" > .gitignore

3. Stage and Commit Changes

Stage your code files and create your first official commit:

git add . git commit -m "feat: initial release for cloud shipping"

4. Link Remote GitHub Repository & Push

Link your remote GitHub repository and push your `main` branch live:

git remote add origin https://github.com/yourusername/my-app.git git branch -M main git push -u origin main
