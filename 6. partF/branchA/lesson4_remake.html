Render & Fly.io Backend Deployment | Track 7A

🐍 Lesson 4: Deploying Backends to Render & Fly.io ☁️ Track 7A • Lesson 4/6

1. Prepare `requirements.txt` & Production Server

Include production WSGI/ASGI servers like `uvicorn` or `gunicorn` in your dependencies:

fastapi==0.110.0 uvicorn==0.28.0 gunicorn==21.2.0

2. Configure Dynamic PORT Binding

Cloud hostings dynamically assign a `$PORT` environment variable. Bind to `0.0.0.0` and read `PORT`:

import os import uvicorn port = int(os.environ.get("PORT", 8000)) uvicorn.run("main:app", host="0.0.0.0", port=port)

3. Create Web Service on Render.com

Click New ➔ Web Service on Render.com, link your GitHub repo, and configure:

Runtime: Python 3 Start Command: uvicorn main:app --host 0.0.0.0 --port $PORT
