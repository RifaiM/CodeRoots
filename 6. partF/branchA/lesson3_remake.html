🟠 Lesson 3: Cloudflare Pages & Edge Delivery ☁️ Track 7A • Lesson 3/6

1. Connect GitHub to Cloudflare Dashboard

Log into Cloudflare Dashboard. Navigate to Workers & Pages ➔ Create Application ➔ Pages ➔ Connect to Git.

2. Configure Build & Framework Settings

Set your framework build output for Cloudflare Pages:

Framework Preset: React / Vite / Custom Build Command: npm run build Build Output Directory: dist

3. Single Page App (SPA) Redirects File (`_redirects`)

To prevent 404 errors on browser refresh in React/SPA apps, create a `public/_redirects` file:

/* /index.html 200

4. Custom CNAME & DNS Setup

Add a CNAME record in your domain registrar DNS pointing to your Cloudflare Pages domain:

Type: CNAME Name: @ or app Target: my-app.pages.dev Proxy Status: Proxied (Orange Cloud)
