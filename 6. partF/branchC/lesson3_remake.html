Server Actions ('use server')

1. Zero-Boilerplate Data Mutations

Server Actions allow React components to execute asynchronous code directly on the server without creating manual API endpoint files or writing fetch() boilerplate.

2. Writing an Async Server Action

Use 'use server' inside an asynchronous function and revalidate cached pages with revalidatePath():

import { revalidatePath } from 'next/cache'; export async function addBookmark(formData: FormData) { 'use server'; const url = formData.get('url'); await db.bookmark.create({ data: { url } }); revalidatePath('/bookmarks'); }

3. Your Practical Task

Write an async Server Action function named addBookmark that contains the 'use server' directive, extracts url from formData.get('url'), and calls revalidatePath('/bookmarks').
