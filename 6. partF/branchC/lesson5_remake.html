Fullstack Database Fetching

1. Direct Database Fetching in Server Components

Because React Server Components execute exclusively on the server, you can query your database directly using SQL or ORMs without exposing database secrets to the browser client.

2. Fetching Data with SQL (`app/posts/page.tsx`)

Query PostgreSQL asynchronously inside a Server Component function:

import { sql } from '@vercel/postgres'; export default async function PostsPage() { const { rows } = await sql`SELECT id, title, created_at FROM posts ORDER BY created_at DESC`; return ( <ul className="space-y-4 p-6"> {rows.map((post) => ( <li key={post.id} className="p-4 bg-slate-800 rounded-lg">{post.title}</li> ))} </ul> ); }

3. Your Practical Task

Write an async Server Component named PostsPage that executes await sql`SELECT * FROM posts` and returns a list <ul> rendering the post titles.
