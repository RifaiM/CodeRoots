Route Handlers (route.ts)

1. App Router REST API Endpoints

Next.js App Router allows creating custom RESTful API endpoints by exporting named HTTP functions (GET, POST, PUT, DELETE) inside a route.ts file.

2. Route Handler Implementation (`app/api/users/route.ts`)

Return JSON responses using NextResponse.json():

import { NextResponse } from 'next/server'; export async function GET() { const users = [ { id: 1, name: 'Alex', role: 'Developer' }, { id: 2, name: 'Sarah', role: 'Architect' } ]; return NextResponse.json({ status: 200, users }); }
