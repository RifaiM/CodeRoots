App Router Architecture

1. Next.js 14/15 App Router Conventions

The app/ directory uses file-based routing. Every route folder contains a page.tsx for UI components and optional layout.tsx for shared headers/sidebars.

2. Basic Page Component (`app/dashboard/page.tsx`)

Export a default React component function to render the route view:

export default function DashboardPage() { return ( <main className="p-8 bg-slate-900 text-white min-h-screen"> <h1 className="text-2xl font-bold">⚡ Analytics Dashboard</h1> <p className="text-slate-400 mt-2">Welcome to Next.js App Router!</p> </main> ); }

3. Your Practical Task

Write a Next.js page component named HomePage in app/page.tsx that returns a <main> element containing an <h1> heading with text "Welcome to NoviCodes Next.js".
