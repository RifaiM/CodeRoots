JWT Stateless Auth

1. JWT Architecture (Header . Payload . Signature)

A JSON Web Token (JWT) is a compact, URL-safe token used for stateless authentication between client and server. Tokens contain 3 dot-separated Base64 parts: Header, Payload (claims), and HMAC-SHA256 Signature.

2. Signing & Decoding Tokens in PyJWT

Generate signed tokens with expiration times (`exp`) using a secret key:

import jwt import datetime SECRET_KEY = 'super_secret_jwt_key' payload = { 'sub': '101', 'username': 'novi_dev', 'role': 'admin', 'exp': datetime.datetime.utcnow() + datetime.timedelta(hours=2) } token = jwt.encode(payload, SECRET_KEY, algorithm='HS256')
