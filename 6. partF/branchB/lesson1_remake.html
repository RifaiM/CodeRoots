SQL Fundamentals

1. Relational Database Concepts

Relational Databases store data in structured Tables consisting of rows and columns. Tables are linked using Primary Keys (unique row IDs) and Foreign Keys (references to other tables).

2. ANSI SQL Syntax Essentials

Use standard SQL commands to query and manipulate data:

SELECT u.username, p.title FROM users u JOIN posts p ON u.id = p.user_id WHERE u.role = 'admin';

3. Your Practical Task

Write an SQL query to retrieve the name and email columns from the users table where role = 'developer'.
