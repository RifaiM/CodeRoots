SQLAlchemy ORM

1. What is an ORM (Object-Relational Mapper)?

An ORM allows developers to interact with relational database tables using native Python objects instead of writing raw SQL strings.

2. Defining SQLAlchemy Models

Define database models by mapping class attributes to database columns using Column, Integer, and String:

from sqlalchemy import Column, Integer, String from sqlalchemy.orm import declarative_base Base = declarative_base() class User(Base): __tablename__ = 'users' id = Column(Integer, primary_key=True) username = Column(String, unique=True, nullable=False) role = Column(String, default='user')
