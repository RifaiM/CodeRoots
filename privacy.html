🔒 Privacy Policy

100% Client-Side LocalStorage Architecture • Zero Data Harvesting

💡 100% LocalStorage Architecture

NoviCodes is built as an open, client-side educational platform. All your XP score, completed lesson checks, unlock states, and code editor work remain strictly stored inside your own web browser's LocalStorage. We do NOT collect, harvest, track, or sell your personal data.

🛡️ 1. Zero Tracking & No Account Needed

NoviCodes does not require user registration, passwords, email addresses, or account creation. You are completely free to start learning immediately without providing any personal identifiers.

We do not use tracking pixels, fingerprinting, or invasive analytics cookies.

💾 2. Local Storage Usage

NoviCodes stores your course progression locally on your device using HTML5 Web Storage (`localStorage`). This data includes:

  • Completed Lesson Keys: Remembers which lessons you have finished (e.g. `partB_lesson1_remake_complete`).
  • XP & Rank Stats: Stores earned experience points and unlocked developer ranks.
  • Code Editor Drafts: Saves your current code draft so you can safely refresh without losing your work.

You can clear or reset this data at any time using the "Reset Course Progress" button in your Learner Profile modal or by clearing your browser cache.

⚙️ 3. Third-Party CDNs & Open Source Assets

To provide high performance and reliable open-source functionality, NoviCodes loads static assets from trusted public content delivery networks (CDNs):

  • Google Fonts: Loads typography fonts (Plus Jakarta Sans, Nunito, Fira Code).
  • SweetAlert2 & GSAP: Loads UI alert popups and smooth animation engines.

These CDNs may process standard technical HTTP headers (such as IP addresses) to serve static asset files securely.

📜 4. Open-Source Transparency

NoviCodes is 100% open-source under the MIT License. You can inspect the source code, review scripts, or fork the codebase directly on GitHub.
