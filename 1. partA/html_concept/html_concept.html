🌳 2. The DOM Tree Hierarchy

Browsers parse HTML into a nested tree structure called the Document Object Model (DOM):

<html> (The Root Document)
  ├── <head> (Page Title, Favicon, SEO Metadata)
  └── <body> (Visible Content)
      ├── <h1> (Main Page Title)
      ├── <p> (Article Body Text)
      └── <button> (Interactive Clickable Action)
