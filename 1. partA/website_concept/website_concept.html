What is a Website?

Discover the digital architecture connecting clients, internet routing, and cloud servers to deliver modern web apps to billions of users.

🏗️ 1. The 3 Core Components of the Web

Every website on earth operates on a Client-Server model. Click each component below to inspect its role:

💻 The Client (Web Browser)

The client is your personal device (laptop, smartphone, or tablet) running a web browser like Chrome, Safari, or Firefox. The browser makes requests, downloads code files, builds the visual DOM layout, and executes JavaScript.

🔗 2. Anatomy of a Web Address (URL)

A URL (Uniform Resource Locator) is like a postal address telling the internet where to locate a file:

https:// novicodes.dev /courses/html
  • Protocol (https://): The secure communication rule between client and server.
  • Domain Name (novicodes.dev): The human-readable name mapped to a server's IP address.
  • Path (/courses/html): The specific route or folder on the server you are visiting.
