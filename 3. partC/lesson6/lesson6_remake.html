Level 5 - Lesson 6: React Controlled Form Inputs & Two-Way Binding

📝 Master React Controlled Inputs & Two-Way Data Binding

In standard HTML forms, input elements store their own values. In React, we use Controlled Components! By binding an <input /> element's value attribute to React State and handling changes with onChange={(e) => setName(e.target.value)}, React state becomes the Single Source of Truth for all form data!

🔒 1. Controlled Component

value={state}

Real-World Analogy: A digital typewriter! Instead of ink directly hitting paper, every keypress sends a signal to a central computer (State), which then displays the letter on screen.

🔄 2. Two-Way Data Binding

State ↔ Input UI

Real-World Analogy: A live mirror! Whatever is stored in state appears inside the input box, and whatever the user types inside the input box updates state instantly!

🎯 3. Event Target Value

e.target.value

Real-World Analogy: Reading a speech bubble! In React event handlers, e.target represents the input field, and e.target.value is the exact text the user typed.

⚡ 4. Instant Live Preview

Real-time Form Sync

Real-World Analogy: ID card printing machine! As you type your name into the computer form, the live badge preview updates letter by letter in real-time.

📦 1. Declare Form State
function ProfileForm() { const [name, setName] = React.useState(""); return <h3>Hello, {name || "Guest"}</h3>; }
⚡ 2. Controlled Input Binding
<input type="text" value={name} onChange={(e) => setName(e.target.value)} />
🎨 3. Controlled Select Dropdown
const [role, setRole] = React.useState("Developer"); <select value={role} onChange={(e) => setRole(e.target.value)}> <option>Developer</option> <option>Designer</option> </select>
🚀 4. Render Form Component
const root = ReactDOM.createRoot( document.getElementById('root') ); root.render(<ProfileForm />);
