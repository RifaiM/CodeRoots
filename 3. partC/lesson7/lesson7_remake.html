Level 5 - Lesson 7: Component Lifecycle & Side Effects (useEffect)

🔄 Master React Component Lifecycle & Side Effects with useEffect

In React, components render UI based on state and props. But what about operations outside rendering, such as fetching API data, setting timers, or subscribing to events? These are called Side Effects! The React.useEffect() Hook lets you execute side effects at specific stages of a component's lifecycle!

⚡ 1. What are Side Effects?

External Operations

Real-World Analogy: A smart home routine! When you enter a room (Mount), the lights turn on automatically (Side Effect). When you leave (Unmount), the lights turn off.

🚀 2. Run Once on Mount []

useEffect(..., [])

Real-World Analogy: Unboxing a new smartphone! Passing an empty dependency array [] tells React: "Run this setup code ONCE when the component first appears!"

🔄 3. State Dependency [city]

useEffect(..., [city])

Real-World Analogy: Motion sensor light! Passing [city] tells React: "Re-run this data fetch effect whenever the city variable changes!"

🧹 4. Effect Cleanup Function

return () => cleanup()

Real-World Analogy: Canceling a subscription! Returning a cleanup function stops timers or listeners when the component unmounts to prevent memory leaks.

📦 1. Fetch Data on Mount []
React.useEffect(() => { fetchArticles().then(data => setNews(data)); }, []); // Empty array = Run ONCE on mount
⚡ 2. Re-fetch on Dependency Change
React.useEffect(() => { fetchWeather(selectedCity); }, [selectedCity]); // Runs when selectedCity changes
🧹 3. Timer & Subscription Cleanup
React.useEffect(() => { const timer = setInterval(tick, 1000); return () => clearInterval(timer); // Cleanup }, []);
🚀 4. Render Fetched State
{loading ? ( <p>⌛ Loading Dev News...</p> ) : ( <ArticleList items={news} /> )}
