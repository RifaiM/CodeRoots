Level 5 - Lesson 8: Component Composition & props.children

🖼️ Master React Component Composition & props.children

In React, components don't always know their children ahead of time! By using Component Composition and the special props.children prop, you can create flexible container components (like Cards, Modals, Drawers, and Layouts) that wrap and style any custom JSX content placed between their opening and closing tags!

🖼️ 1. Picture Frame (props.children)

{children}

Real-World Analogy: A picture frame! The frame component provides the border, background, and padding, but you can place any picture (JSX content) inside it!

🍱 2. Bento Box (Layout Slots)

header={...}

Real-World Analogy: A meal bento box! You can pass different dishes (JSX components) into custom slot props like header={...} and footer={...}.

🧱 3. Lego Bricks (Composition)

Flexible Nesting

Real-World Analogy: Building with Lego! Instead of crafting giant monolithic files, assemble complex UIs by nesting smaller container components together.

🧰 4. Generic Shell Containers

Reusable Wrapper

Real-World Analogy: A shipping container! It doesn't care what cargo is inside — it standardizes protection, styling, and layout structure for all contents.

📦 1. Container with props.children
function CardShell({ title, children }) { return ( <div className="card"> <h3>{title}</h3> <div>{children}</div> </div> ); }
⚡ 2. Nesting Custom JSX Content
<CardShell title="User Stats"> <p>Active Members: <strong>1,250</strong></p> <button>View All</button> </CardShell>
🎨 3. Custom Slot Props
function Modal({ header, body }) { return ( <div> <header>{header}</header> <main>{body}</main> </div> ); }
🚀 4. Render Composed Tree
const root = ReactDOM.createRoot( document.getElementById('root') ); root.render(<DashboardApp />);
