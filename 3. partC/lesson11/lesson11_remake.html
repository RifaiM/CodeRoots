Level 5 - Lesson 11: Single Page Application Routing

🧭 Master Single Page Application Routing & View Navigation

In traditional websites, clicking a link forces the browser to request a whole new HTML file from the server. In Single Page Applications (SPAs), a Client-Side Router intercepts navigation actions to switch view components instantly without refreshing the browser!

🧭 1. GPS Navigation System

Client-Side Router

Real-World Analogy: A car GPS dashboard! Switching screens from Map to Music doesn't restart your car engine — it swaps the display content seamlessly on the same screen!

🗂️ 2. Tabbed Binder (Route State)

route === "home"

Real-World Analogy: A divider tab in a binder! Changing the route state variable flips the current active page tab instantly without reloading the binder.

🎨 3. Active Nav Link Styling

nav-link active

Real-World Analogy: A glowing elevator floor button! Highlighting the active link gives users instant visual feedback on which route view they are currently inspecting.

🚦 4. Fallback 404 Route

Default Route Guard

Real-World Analogy: A detour signpost! If a user navigates to an unknown route path, the router displays a friendly "Page Not Found" fallback screen.

📦 1. Declare Client Route State
function AppRouter() { const [route, setRoute] = React.useState("home"); return <NavHeader currentRoute={route} onNavigate={setRoute} />; }
⚡ 2. Custom Link Component
<button className={currentRoute === "docs" ? "active" : ""} onClick={() => onNavigate("docs")}> Docs </button>
🎨 3. Conditional Route Matching
{route === "home" && <HomePage />} {route === "dashboard" && <DashboardPage />} {route === "settings" && <SettingsPage />}
🚀 4. Render SPA Router
const root = ReactDOM.createRoot( document.getElementById('root') ); root.render(<AppRouter />);
