🍱 Understanding React Components & Virtual DOM

In traditional web development, you write HTML line-by-line and manually search for elements using JavaScript (document.getElementById). But in React, we think in Components! A component is a self-contained, reusable building block that combines HTML structure, CSS layout, and JS logic into one neat package.

🧩 1. The Component Blueprint

function Header()

Real-World Analogy: Building with LEGO bricks! Instead of molding one giant 10-foot block of plastic for a house, you click together reusable LEGO bricks (doors, windows, roof tiles). In React, <Header /> and <Card /> are your custom LEGO bricks!

🌳 2. Component Tree Hierarchy

<App><Header /></App>

Real-World Analogy: A nested Bento Box! The main bento box (<App />) holds smaller food compartments (<Header />, <Card />, <Footer />). Components easily nest inside each other to create complex web apps!

👨‍🍳 3. Declarative UI vs Imperative

UI = f(state)

Real-World Analogy: Ordering food from a restaurant chef!
• Imperative (Vanilla JS): Walking into the kitchen and telling the chef every step: "Turn on stove, drop butter, crack egg..."
• Declarative (React): Pointing to menu item #4: "I want a fried egg!" React handles the kitchen steps for you!

⚡ 4. The Virtual DOM

ReactDOM.createRoot()

Real-World Analogy: A smart blueprint checker before building! Instead of knocking down an entire wall when one brick changes, React's Virtual DOM compares the old and new blueprints, updating ONLY the changed brick in milliseconds.

🧩 Define a Sub-Component
function Header() { return ( <header> <h1>🍱 Component Dojo</h1> </header> ); }
🎁 Component with Props
function Card({ title }) { return ( <div className="card"> <h3>{title}</h3> </div> ); }
🌳 Assemble Component Tree in App
function App() { return ( <div> <Header /> <Card title="Virtual DOM" /> </div> ); }
🚀 Render Component Tree to DOM
const root = ReactDOM.createRoot( document.getElementById('root') ); root.render(<App />);
