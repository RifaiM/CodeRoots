Level 5 - Lesson 12: Building Custom React Hooks

🧰 Master Building Custom React Hooks & Reusable Stateful Logic

When multiple components need to share the same stateful logic (such as saving data to localStorage, toggling modals, or fetching API data), copy-pasting code is bad practice! By building Custom Hooks (functions starting with use...), you can package complex React logic into reusable, modular helpers!

🧰 1. Swiss Army Knife (Custom Hook)

useLocalStorage(...)

Real-World Analogy: A Swiss Army Knife! Instead of carrying separate loose tools everywhere, package all your favourite gadgets into a single portable handle.

💾 2. Auto-Save Memory (useLocalStorage)

useState + useEffect

Real-World Analogy: An auto-saving notebook! Every time you write a line, the custom hook automatically saves it to browser storage so your data survives reloads.

💡 3. Light Switch (useToggle)

const [on, toggle] = useToggle()

Real-World Analogy: A wall light switch! Instead of wiring boolean state manually every time, useToggle provides a single switch handler.

📦 4. Custom Hook API Return

return [value, setValue]

Real-World Analogy: A standardized power outlet! Custom hooks return tuples `[state, updater]` or objects `{ data, loading }` that fit seamlessly into any component.

📦 1. Declare Custom Hook Function
function useLocalStorage(key, initialVal) { const [state, setState] = React.useState(() => { const item = localStorage.getItem(key); return item ? JSON.parse(item) : initialVal; }); return [state, setState]; }
⚡ 2. Encapsulate Side Effects
React.useEffect(() => { localStorage.setItem(key, JSON.stringify(state)); }, [key, state]);
🎨 3. Build a Custom useToggle Hook
function useToggle(initialState = false) { const [value, setValue] = React.useState(initialState); const toggle = () => setValue(v => !v); return [value, toggle]; }
🚀 4. Consume Custom Hook in UI
function ProfileApp() { const [name, setName] = useLocalStorage("name", "Alex"); const [isDark, toggleDark] = useToggle(false); return <div>{name}</div>; }
