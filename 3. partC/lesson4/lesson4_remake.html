Level 5 - Lesson 4: React Props & Reusable Data Flow

🎁 Master React Props & Reusable UI Data Flow

In React, Props (short for Properties) allow components to receive custom dynamic data from their parent components. Props make your UI components truly reusable! Instead of hardcoding text or prices inside every card, props allow one single <ProductCard /> component to render hundreds of unique products dynamically!

🍕 1. What are Props?

<Card title="Headphones" />

Real-World Analogy: Ordering custom pizza toppings! The base dough is the reusable component (<Pizza />), but the custom toppings you pass in (topping="pepperoni", size="large") are the Props!

🌊 2. One-Way Top-Down Data Flow

Parent → Child

Real-World Analogy: A mountain waterfall! In React, data flows strictly top-down from parent components (<App />) to child components (<ProductCard />). Children read props but never mutate parent props directly.

📦 3. Prop Destructuring

function Card({ name, price })

Real-World Analogy: Unboxing a delivery parcel! Instead of writing props.name and props.price everywhere, JS ES6 destructuring unboxes props right at the component parameter: ({ name, price }).

⚡ 4. Reusable UI Components

1 Component = N Instances

Real-World Analogy: A cookie cutter! Write the component blueprint ONCE, and stamp out infinite custom instances with different prop values: <ProductCard name="Keyboard" /> and <ProductCard name="Mouse" />.

📦 1. Destructure Props in Child
function ProductCard({ name, price }) { return ( <div className="card"> <h3>{name}</h3> <p>\${price}</p> </div> ); }
🎁 2. Pass Props from Parent
function App() { return ( <div> <ProductCard name="Keyboard" price={129} /> <ProductCard name="Mouse" price={69} /> </div> ); }
🛡️ 3. Default Prop Values
function Badge({ label = "New" }) { return <span className="badge">{label}</span>; }
🚀 4. Render App Component Tree
const root = ReactDOM.createRoot( document.getElementById('root') ); root.render(<App />);
