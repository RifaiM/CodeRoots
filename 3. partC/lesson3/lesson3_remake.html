Level 5 - Lesson 3: JSX Syntax & Dynamic Rendering

⚡ Master JSX & Dynamic UI Rendering

JSX (JavaScript XML) is React's powerful syntax extension that lets you write HTML-like code directly inside JavaScript! Under the hood, Babel compiles your JSX into plain React.createElement() functions. JSX unlocks supercharged dynamic templates powered by JavaScript expressions inside {} curly braces!

🥪 1. What is JSX?

<h1>Hello World</h1>

Real-World Analogy: A delicious sandwich! HTML is the bread structure, but JavaScript inside {} is the flavorful filling. JSX seamlessly merges markup and logic into one component!

🔮 2. The {} Magic Window

{userName} / {2 + 2}

Real-World Analogy: A live magic window into JavaScript! Anything placed inside {} (variables, math, function calls) gets evaluated live and rendered straight into the DOM.

🏷️ 3. JSX Rules: className & Self-Closing

className="card" <img />

Real-World Analogy: Strict grammar rules! Since class is a reserved JS keyword, JSX uses className. Also, void HTML tags like <img> or <br> MUST be self-closed with a trailing slash: <img />.

🔄 4. List Mapping with .map()

skills.map((item, idx) => ...)

Real-World Analogy: A high-speed stamp printer! Instead of copy-pasting HTML 10 times, .map() iterates over an array of data and prints a dynamic UI element for each item automatically.

🔮 Dynamic JS Expressions
const name = "Alex"; return <h2>Welcome, {name}!</h2>;
🏷️ className & Self-Closing Tags
return ( <div className="avatar-card"> <img src={userPic} alt="User" /> </div> );
🔄 Render Dynamic Lists
const items = ["React", "JS"]; return ( <ul> {items.map((item, i) => ( <li key={i}>{item}</li> ))} </ul> );
🚀 Render JSX Root Component
const root = ReactDOM.createRoot( document.getElementById('root') ); root.render(<ProfileCard />);
