⚡ Master React State & Interactive Events with useState

In standard JavaScript, changing a variable doesn't update what the user sees on screen. In React, components use State! When a component's state changes, React automatically re-renders the component to reflect the new state instantly. The React.useState() Hook gives your components memory and interactivity!

🧠 1. Memory of a Component

React.useState(initialValue)

Real-World Analogy: A digital scorekeeper! State is like a digital display board that holds a number. When a team scores, the scoreboard updates and everyone sees the new score immediately.

🎛️ 2. Value + Setter Function

const [count, setCount] = ...

Real-World Analogy: A TV screen + remote control! count is the current channel shown on screen, and setCount is the remote control button that changes the channel.

🖱️ 3. JSX Event Handlers

onClick={() => setCount(...)}

Real-World Analogy: Pressing a light switch! In React JSX, event attributes use camelCase like onClick, passing a function that triggers when the user clicks.

🔄 4. Reactive UI Re-rendering

State Change → Auto UI Update

Real-World Analogy: A live sports scoreboard! You never manually erase and redraw HTML. Calling setCount(count + 1) tells React: "Hey, update this component on screen right now!"

📦 1. Declare State in Component
function Counter() { const [count, setCount] = React.useState(0); return <h2>Count: {count}</h2>; }
⚡ 2. Bind onClick Event Handler
<button onClick={() => setCount(count + 1)}> ➕ Increase </button>
💖 3. Toggle Boolean State
const [isLiked, setIsLiked] = React.useState(false); <button onClick={() => setIsLiked(!isLiked)}> {isLiked ? "❤️ Liked" : "🤍 Like"} </button>
🚀 4. Render State Component
const root = ReactDOM.createRoot( document.getElementById('root') ); root.render(<Counter />);
