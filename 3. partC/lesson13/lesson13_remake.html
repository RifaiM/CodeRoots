Level 5 - Lesson 13: Context API & Global State Management

📡 Master React Context API & Global State Management

Passing props down through 5 layers of intermediate components just to reach a deeply nested child is called Prop Drilling — and it quickly leads to messy code! By using the React Context API (createContext and useContext), you can broadcast global state (like user auth, theme, and language) to any component in your app directly!

📡 1. Satellite Broadcast

createContext()

Real-World Analogy: Satellite Wi-Fi! Instead of stringing long physical wires to every room (prop drilling), a central satellite broadcasts data through the air to any device.

🏰 2. Central Power Station

<Context.Provider>

Real-World Analogy: A power station! Wrapping your app with <Provider value={...}> energizes the entire component tree with shared state and updater functions.

🔌 3. Wall Outlet (useContext)

useContext(AuthContext)

Real-World Analogy: Plugging into a wall socket! Any child component can tap directly into global state with useContext without asking parent components to pass props down.

🚫 4. Banishing Prop Drilling

Clean Component Tree

Real-World Analogy: Direct elevator access! Skip climbing 5 flights of stairs (intermediate props) and take the express elevator straight to global state.

📦 1. Create Context Object
const ThemeContext = React.createContext(null);
⚡ 2. Provide Context Value
<ThemeContext.Provider value={{ theme, toggleTheme }}> <AppLayout /> </ThemeContext.Provider>
🎨 3. Consume Context in Deep Child
function UserBadge() { const { theme, toggleTheme } = React.useContext(ThemeContext); return <button onClick={toggleTheme}>{theme}</button>; }
🚀 4. Render Global Context Portal
const root = ReactDOM.createRoot( document.getElementById('root') ); root.render(<GlobalAppProvider />);
