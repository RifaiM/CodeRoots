🎛️ Master Lifting State Up & Cross-Component Communication

In React, sibling components cannot talk directly to each other! When two or more components need to share data, we Lift State Up to their closest common parent component. The parent holds the shared state and passes callback functions down to children so user actions flow UP and updated state flows DOWN!

🎛️ 1. Central Switchboard

Parent State

Real-World Analogy: A central airport tower! Flight control (Parent Component) holds all flight data and coordinates communication between ground crew and pilots (Child Components).

📞 2. Callback Props

onSelect={handleSelect}

Real-World Analogy: A walkie-talkie button! The parent hands a walkie-talkie (callback prop) to a child. Pressing the button sends a message back UP to the parent control room!

📡 3. Sibling Data Sync

Sibling A → Parent → Sibling B

Real-World Analogy: A live scorekeeper! When Team A scores a point (Child Event), they notify the scorekeeper (Parent State), who instantly updates the giant stadium display (Sibling UI)!

🌊 4. One-Way Data Flow

Props Down, Events Up

Real-World Analogy: A waterfall & elevator! Data flows gracefully DOWN via props like a waterfall, while events travel UP via callbacks like an elevator.

📦 1. Declare Shared State in Parent
function StoreParent() { const [cart, setCart] = React.useState([]); const handleAdd = (item) => setCart([...cart, item]); return <StoreLayout cart={cart} onAdd={handleAdd} />; }
⚡ 2. Pass Callback Prop to Child
<ItemSelector items={products} onAddToCart={(item) => handleAddToCart(item)} />
📞 3. Trigger Callback in Child
function ItemCard({ item, onAddToCart }) { return ( <button onClick={() => onAddToCart(item)}>Add</button> ); }
🚀 4. Receive State in Sibling UI
function CartSummary({ cartItems }) { return ( <h3>Total Cart Items: {cartItems.length}</h3> ); }
