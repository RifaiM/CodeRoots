📁 File Handling & Context Managers

In server backend architecture, applications frequently write to system log files, parse configuration files, and persist data. Python provides safe, robust file operations using the with open(...) as file: context manager, which guarantees files are automatically closed even if unexpected runtime errors occur.

Real-World Analogy: Using with open() is like an automated security lock for a safe. Once you finish reading or writing files, the safe automatically locks itself without relying on manual closing!
📝 1. Writing Files (with open)
# Open file in write mode ("w")
with open("app.log", "w") as f:
  f.write("Server started at 12:00\n")
  f.write("Port 8080 active\n")
📖 2. Reading File Content
# Open file in read mode ("r")
with open("app.log", "r") as f:
  data = f.read()
  print(data)
