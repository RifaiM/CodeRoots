🔀 Python Control Flow: Conditionals & Loops

In backend programming, your code needs to make smart decisions and process repetitive data efficiently. Python makes control flow clean and readable using if statements, for loops, and colon `:` syntax with 2-space indentation.

Real-World Analogy: Control flow is like a smart traffic signal or security check. If a user is authorized, let them enter; otherwise, prompt for login!
🔀 1. Conditionals (if, elif, else)
score = 85
if score >= 90:
  print("Rank: S")
elif score >= 80:
  print("Rank: A")
else:
  print("Rank: B")
🔄 2. For Loop & Range
# Loop 5 times from 1 to 5
for i in range(1, 6):
  print(f"Iteration #{i}")
