🧱 Object-Oriented Programming (OOP) in Python

In production backend engineering, complex entities (such as Users, Products, and Database Connections) are organized using Object-Oriented Programming (OOP). A Class is a blueprint for creating objects, bundling data attributes and methods together.

Real-World Analogy: A Class is like an architectural blueprint for a building; an Object (Instance) is the actual constructed building created from that blueprint!
💡 Demystifying __init__ & self: __init__ is the setup function that automatically runs when a new object is created. self simply refers to "this specific object" being configured right now!
🧱 1. Class Blueprint & __init__
class Server:
  # Initializer method with self
  def __init__(self, host, port=8080):
    self.host = host
    self.port = port
📱 2. Methods & Instantiation
  def get_url(self):
    return f"http://{self.host}:{self.port}"

# Instantiate server object
s1 = Server("localhost")
print(s1.get_url())
