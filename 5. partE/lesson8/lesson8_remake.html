📦 Python Modules & Standard Library

Python comes with a rich Standard Library containing pre-built modules for mathematics, cryptography, date handling, and networking. Instead of building utilities from scratch, you can organize your backend application using import and from ... import ... statements.

Real-World Analogy: Importing a module is like pulling a specialized tool from a backend toolbox. Need high-precision math? Import math. Need token generation? Import random!
📦 1. Basic Module Import
import math
import random

# Use module functions
val = math.sqrt(64) # Output: 8.0
num = random.randint(1, 100)
⚡ 2. Selective Import (from ... import ...)
from datetime import datetime

# Access imported class directly
now = datetime.now()
print(f"Timestamp: {now}")
