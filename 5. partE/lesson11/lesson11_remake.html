🗄️ Relational Databases & SQLite3 Integration

Production backends rely on Relational Database Management Systems (RDBMS) to store structured records permanently. Python includes sqlite3 out of the box, letting you execute SQL queries, insert records, query database tables, and manage transactional commit() calls.

Real-World Analogy: A database connection is like a secure hotline to your data warehouse. A cursor is like a forklift operator that executes SQL instructions (pick, store, update) inside the warehouse!
💡 Demystifying commit() & cursor: Executing SQL statements builds changes in temporary memory; calling conn.commit() saves those changes permanently to disk so your data isn't lost when the server restarts!
🗄️ 1. Connecting & Executing SQL
import sqlite3

# Connect to SQLite in-memory DB
conn = sqlite3.connect(":memory:")
cursor = conn.cursor()

# Create SQL table
cursor.execute("CREATE TABLE users (id INT, name TEXT)")
💾 2. Committing Transactions & Querying
# Insert record & commit
cursor.execute("INSERT INTO users VALUES (1, 'Alex')")
conn.commit()

# Fetch records
cursor.execute("SELECT * FROM users")
rows = cursor.fetchall()
