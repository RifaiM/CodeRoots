🧬 Class Inheritance & Method Overriding

In backend architecture, specialized classes often share attributes and logic with a general base class. Class Inheritance allows a child subclass to inherit all methods and properties from a parent class, extending or overriding behaviors using the super() function.

Real-World Analogy: A base User model handles common fields (like username and email), while specialized AdminUser or SubscriberUser subclasses extend it with custom privileges!
🧬 1. Subclass Inheritance (Child(Parent))
class User:
  def __init__(self, name):
    self.name = name

# AdminUser inherits from User parent
class AdminUser(User):
  pass
⚡ 2. super() & Method Overriding
class AdminUser(User):
  def __init__(self, name, level):
    # Call parent constructor
    super().__init__(name)
    self.level = level
