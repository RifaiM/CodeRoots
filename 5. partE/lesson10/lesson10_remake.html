⚡ Asynchronous Python & Asyncio Event Loops

Modern high-performance backend frameworks (such as FastAPI and Tornado) rely on asynchronous programming. Instead of blocking the server CPU while waiting for database queries or API responses, Python uses async def coroutines and await to process thousands of concurrent requests smoothly.

Real-World Analogy: Synchronous code is like a restaurant chef who cooks one dish from start to finish before taking the next order. Asynchronous code is like a chef who puts a steak in the oven, and while it bakes (await), prepares appetizers for other customers!
💡 Demystifying async & await: async def tells Python "this function can pause to wait for slow data," while await tells Python "pause here until the database responds, but keep serving other users in the meantime!"
⚡ 1. Async Coroutines (async def)
import asyncio

# Define asynchronous coroutine
async def fetch_data():
  print("Fetching DB record...")
  await asyncio.sleep(1)
  return {"status": 200}
⏳ 2. Event Loop Execution
async def main():
  res = await fetch_data()
  print(res)

# Run event loop
asyncio.run(main())
