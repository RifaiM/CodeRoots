⚡ Lesson 3: Modular Code with Python Functions

In backend architecture, writing code repeatedly leads to bugs and maintenance nightmares. Functions are self-contained blocks of reusable logic that accept input parameters, process data, and return computed results back to your application.

💡 Backend Concept: Think of a function as a microservice endpoint. You send it arguments (inputs), it executes internal logic, and returns a response string or value using the return keyword!

⚙️ Function Definition & Return

def calculate_total(base, bonus):
    # Compute and return calculated total
    total = base + bonus
    return total

# Call function & store return value
score = calculate_total(1000, 500)
print(score) # Output: 1500

📥 Default Parameters & Docstrings

def format_user(name, role="Member"):
    """Return formatted developer profile."""
    return f"[{role}] {name}"

# Uses default parameter role="Member"
print(format_user("Alex"))
# Overrides default role
print(format_user("Sam", "Admin"))
