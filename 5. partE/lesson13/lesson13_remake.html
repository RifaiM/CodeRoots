🔒 Password Hashing & JWT Authentication

Security is paramount in backend engineering. You must never store plain-text passwords in databases. Instead, passwords are cryptographic hashed (SHA-256 / bcrypt) with hashlib, and user sessions are authenticated statelessly using signed JSON Web Tokens (JWT) containing token claims.

Real-World Analogy: Password hashing is like a one-way paper shredder that transforms a password into a unique fingerprint hash. A JWT token is like a digital VIP event pass stamped with a cryptographically verified signature!
🔒 1. Password Hashing (hashlib)
import hashlib

# Convert plain password to SHA-256 hash
pw = "MySecret123"
hashed = hashlib.sha256(pw.encode()).hexdigest()
print(hashed)
🔑 2. JWT Generation & Token Claims
# JSON Web Token structure
payload = {
  "sub": "101",
  "role": "admin"
}
token = JWT.encode(payload)
