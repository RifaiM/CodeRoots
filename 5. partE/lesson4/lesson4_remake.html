📦 Python Data Structures: Lists & Dictionaries

Backend systems process complex collections of data, such as API responses, database records, and server logs. Python provides powerful built-in data structures: Lists [] for ordered collections and Dictionaries {} for key-value records.

Real-World Analogy: A Python List is like an array of database records; a Dictionary is like a JSON object sent back by a REST API endpoint!
📦 1. Python Lists (Ordered Collections)
# Create a list of server hostnames
servers = ["web-01", "db-primary", "cache"]

# Access items by 0-based index
print(servers[0]) # Output: web-01
servers.append("api-gateway")
🔑 2. Python Dictionaries (Key-Value Objects)
# Create a dictionary representing user profile
user = {
  "username": "Alex",
  "role": "admin",
  "level": 6
}

# Access value by key
print(user["username"])
